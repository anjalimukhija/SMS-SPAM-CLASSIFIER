Email/SMS Spam Classifier

A Machine Learning based web application that classifies messages as Spam or Not Spam using Natural Language Processing (NLP).

Features

Enter an SMS or email message.

Predict whether the message is Spam or Not Spam.

Interactive web interface built using Streamlit.

Text preprocessing using NLTK.

Machine Learning model with TF-IDF vectorization.

Tech Stack

Python

Streamlit

Scikit-learn

NLTK

Pickle

Project Files

app.py – Streamlit web application.

model.pkl – Trained classification model.

vectorizer.pkl – TF-IDF vectorizer.

requirements.txt – Required Python libraries.

Run Locally

Clone this repository.

Install the dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
